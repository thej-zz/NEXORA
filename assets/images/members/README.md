Drop real member photos in this folder, then point to them from
js/data/members.js (the `image` field on each member), e.g.:

  { name: "Mahadev - Jefin", role: "President", image: "./assets/images/members/mahadev.jpg" }

Recommended: square-ish or 4:5 portrait crops, at least 800px on
the short side, JPG or WebP. Until a photo is added, that member's
card automatically shows a graceful initials placeholder instead
of a broken image — nothing needs to change in the HTML.
